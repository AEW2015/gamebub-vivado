# GameBub Vivado board files

This source distribution includes **GameBub Rev4, board-file version 2.0**, its image, pin map, presets and custom bus definitions. File version 2.0 keeps the Rev4 hardware contract and avoids Vivado 2025.2's Latest-selection ordering problem with versions 1.9 and 1.10. Historical board versions and lab projects are not included.

Follow the [quickstart](../../QUICKSTART.md). Source `install_gamebub_current_repositories.tcl` at the welcome screen for board discovery and again after project creation for the selected IP repositories. Do not register the entire development archive or use an older installer against this curated source tree.

See the [product guides](../../docs/vivado/README.md), [clock/reset guide](../../docs/vivado/clocks-resets.md) and [qualification status](../../docs/vivado/validation.md). Board definitions describe physical wiring, not proof of timing closure or a controller for every interface.
