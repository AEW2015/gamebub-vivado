GameBub ESP32 Communications and Overlay

Version 1.14 | Vivado 2025.2 | GameBub Rev4 / Rev4.1

Always-on ESP32 QSPI, active-high IRQ gate and twelve-button service.
Use 200 MHz service_clk; use an AXI Clock Converter for a different CPU clock.

Board and IPI workflow

  1. For a new project, source board_files/install_gamebub_current_repositories.tcl before and after creating the project, and select GameBub board 1.10 before adding IP. Historical projects retain the full-repository installer until deliberately upgraded.
  2. Add this IP from the catalog. All physical GameBub IP use the same native Board tab; choose the matching interface or Custom.
  3. Bind physical interfaces using board selection and Make External, board-component binding, or the Tcl commands below.
  4. Connect every clock/reset and processor/video interface; assign full address apertures; validate the BD before generating output products.
apply_board_connection -board_interface mcu_qspi -ip_intf YOUR_INSTANCE/QSPI -diagram [current_bd_design]
apply_board_connection -board_interface buttons_12bits -ip_intf YOUR_INSTANCE/BUTTONS -diagram [current_bd_design]
apply_board_connection -board_interface mcu_irq_gate -ip_intf YOUR_INSTANCE/IRQ_GATE -diagram [current_bd_design]

The built-in xilinx.com:bd_rule:board accepts a fixed list of AMD interface types. Use the explicit binding above for custom GameBub VLNVs; native GPIO/clock automation is separate. Do not modify installed AMD scripts.

Configuration

Overlay video

Optional native 480 x 800 AXI4-Stream, one RGBA pixel per beat.
ESP32 pixels have priority above the separate CPU bitmap.
Disabling removes overlay connections; reconnect clock, reset and AXIS when re-enabled.

Control / Tcl parameterDefaultMeaning
Enable AXI4-Stream overlay output
C_ENABLE_OVERLAY_AXIS		falseWhen disabled, no video RAM is generated and QSPI/IRQ still run independently. Vivado removes disabled clock/reset/interface connections; reconnect them after re-enabling this option.
Use black/white ESP32 overlay
C_OVERLAY_MONOCHROME		trueOn: 6 BRAM36 with independent opacity. Off: full ARGB1555 storage uses 48 BRAM36.
Enable CPU pixel writer
C_ENABLE_CPU_OVERLAY		falseCOV2: 384 x 240, independent opacity and black/white per pixel. Adds 16 RAMB18 (8 BRAM36 equivalent); CPU index/data registers start at +0x200.
Overlay stream clock (Hz)
C_OVERLAY_CLK_HZ		29361979Clock metadata only, not a clock generator. Match overlay_clk and the receiving LCD/FIFO; for the standard pixel clock use the Clocking Wizard's actual integer frequency.

Diagnostics

Manual IRQ forcing is for controlled debugging only; normal ESP32 handshaking does not need it.

Control / Tcl parameterDefaultMeaning
Allow manual IRQ assertion
C_MANUAL_OVERRIDE		00: normal automatic IRQ only (recommended). 1: also permit the diagnostic manual gate register.
